Варианты с обычным `const` вычисляются во время выполнения программы, в то время варианты с `constexpr` вычисляются уже во время его компиляции.

### Задание 2 **(2)** ✅
*Проверьте работу следующей программы на С++*
```
#include <iostream>
int main() {
   {
      int x, y;
      std::cin >> x >> y;
      std::cout << x+y << std::endl;
   }
   {
      double x, y;
      std::cin >> x >> y;
      std::cout << x+y << std::endl;
   }
   return 0;
}
```
*Нужны ли в этой программе вложенные фигурные скобки? Дайте подробный ответ с объяснением причин.*

---

Да, нужны. Фигурные скобки (области видимости) изолируют блоки кода внутри одной функции и они выполняются последовательно.
Если их убрать, то программа попросту не скомпилируется, т.к. теперь будет повторное определение x и y.

int s = 0;

### Задание 4 **(2)** ✅
*Проверьте работу следующего фрагмента программы на* **Python**.
```
s = 0
for i in range(4):
   for i in range(3):
      s += i
   s += i
print(s)
```
*В результате каких вычислений был получен ответ? Дайте подробный ответ.*

*На основе этих примеров поясните различия между* **С++** и **Python** *при работе с переменными*.

---

Сначала идёт внутренний цикл `(0+(0+1+2)=3)`, однако Python не создаёт новую переменную, а берёт уже созданную i и по итогу вместо ожидаемого 0 получается 2 `(3+2=5)`.
На второй итерации внутренний цикл также проходит как нужно `(5+(0+1+2)=8)`, однако на выходе i снова становится равным 2 `(8+2=10)`, и так до конца цикла.
`(10+(0+1+2)=13; 13+2=15)` `(15+(0+1+2)=18; 18+2=20)`

Дело в том, что в Python циклы не создают области видимостей, их могут делать только функции, классы и модули.

### Задание 9 **(3)** ✅
*Напишите программу на языке* **Python**, *которая создаст 2600 переменных с именами
от* **a0** *до* **a99**, *от* **b0** *до* **b99** *и так далее, от* **z0** *до* **z99**. 
*Присвойте всем переменным различные значения от 1 до 2600.*

---

```python
current_value = 1

for letter_code in range(ord('a'), ord('z') + 1):
    letter = chr(letter_code)

    for num in range(100):
        var_name = f"{letter}{num}"
        globals()[var_name] = current_value
        current_value += 1
```
