### Задание 1 (3) ✅
* **Тип в программировании** - атрибут объекта данных, задающий множество допустимых значений и методы для работы с ними.
* **Статическая типизация** - тип объекта определяется в момент трансляции.
* **Динамическая типизация** - тип объекта данных определяется на этапе выполнения программы в момент создания или присваивания значения.
* **Неявная типизация** - тип определяется на этапе трансляции автоматически по тексту программы.
* **Явное преобразование типа** - преобразование типа, если оно указано в программе в виде вызова функции или в виде операции
* **Неявное преобразование типа** - преобразование типа, если оно не присутствует в программе в виде конкретного указания, однако транслятор сам подставляет требуемый метод преобразования.
* **Сильная типизация** - язык программирования (почти) не содержит правил неявного преобразования типа.
* **Слабая типизация** - язык программирования содержит большое число правил неявного преобразования типа, допускает каламбуры типизации.

- Преобразование из вещественных в целочисленные: отсечение дробной части;

*Преобразования при присваивании*
- При присваивании значение правого операнда приводится к типу левого операнда.

*Преобразования при арифметических действиях*
- Если длины обоих типов меньше int, то преобразование к int;
- Если типы разной длины, то преобразуется меньший к большему;
- Если типы равной длины и один знаковый, а другой беззнаковый, то знаковый приводится к беззнаковому;

*Преобразования с логическими значениями*
- Результат условного выражения в инструкциях ветвления и цикла приводится к логическому типу;
- Если оператор требует логического значения, то операнды приводятся к логическому типу (логические операции);
- Преобразование в bool: 0 — false; остальные значения — true;
- Преобразование из bool: false — 0; true — 1.

### Задание 6 (2) ✅ 
```
int a = -1, b = 1;
unsigned int c = 1;
std::cout << a*b << std::endl;
std::cout << a*c << std::endl;
```

---

1. При `a*b` никакого приведения не требуется (оба имеют тип int). В `a*c` при бинарных операциях с имеющими одинаковую разрядность
знаковыми и беззнаковыми типами применяются обычные арифметические преобразования. Тип int неявно преобразуется к беззнаковому типу (unsigned int). 
В двоичном виде число -1 записывается как 0xFFFFFFFF, что в беззнаковом типе дает 4294967295. Следовательно, `4294967295 x 1 = 4294967295`.
2. Если же заменить типы на short и unsigned short, поведение изменится. В C++ к типам меньше int перед вычислением применяется правило целочисленного продвижения.
Так как тип int легко вмещает в себя абсолютно все возможные значения типа unsigned short (от 0 до 65535), обе переменные a и c перед умножением неявно продвигаются
именно к знаковому int, а не к unsigned. В результате операция a*c выполняет умножение двух чисел типа int (-1 x 1), и программа выводит -1 вместо огромного положительного числа.

Далее между ними есть оператор +. Оператор не определен для типа bool, поэтому по правилам неявного преобразования типов типы bool автоматически приводятся к целочисленному типу int.
Далее уже происходит сравнение int с bool (true). При сравнении int и bool значение true справа неявно преобразуется в int и становится равным 1. Соответственно равенство выполняется только когда одна из скобок возвращает true.

### Задание 9 (2) ✅
Программа на Python запускается без ошибок и выводит правильный результат.

Программа на Java отказывается как-либо компилироваться, так как при вычислении левой части получается логическое значение и дальнейшее вычисление Java видит как `true == 5`. В Java строго запрещено сравнивать булевы значения с числами.
